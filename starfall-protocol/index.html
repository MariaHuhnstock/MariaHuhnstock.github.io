01

Design

Endless shooters usually punish only the player. Starfall adds a second health bar – Earth – so letting an enemy slip past is a real decision with a cost. Runs stay short so failure feels like an invitation to try again.

Design pillars

P1

Every miss costs

Enemies that get past damage Earth. Losing Earth ends the run.

P2

Short runs, fast retries

About five minutes per run, straight back in after game over.

P3

Readable escalation

Difficulty rises wave by wave, peaking in a multi-phase boss.

Core loop

  1. Fly & shoot→
  2. Clear wave→
  3. Pick upgrade→
  4. Next wave escalates↺ repeat
  1. Enemy slips past→
  2. Earth takes damage→
  3. Earth at 0 = game over

Key decisions

Object pooling

Enemies and projectiles are reused instead of instantiated, keeping frame times stable in dense waves.

ScriptableObjects

Upgrades and enemy stats live in data assets, so balancing happens in the Inspector, not in code.

Enemy state machine

Each enemy type combines shared states, which keeps new behaviours – and the boss phases – small and testable.
