Portfolio website of Maria Huhnstock, a Game Design & Development graduate focused on **game design, gameplay programming, prototyping and Unity/C#**.

The website presents three focused case studies with their design goals, system logic, documented rules and my concrete contributions.

## Selected projects

### Don't Look

A first-person psychological horror prototype built with Unity and C#. I designed and implemented the task flow, object interactions, contextual feedback and scripted horror events.

### SpaceBastion

A university team project built with Unity and C#. My contribution focused on adjustable weather, lighting and day/night systems with designer-facing controls.

### Vertical Shooter

A self-contained openFrameworks/C++ learning project. I designed and implemented the combat loop, enemy types, boss scaling, upgrades, shop system and persistent highscores.

## Focus

- Game Design and Gameplay Systems
- Game Programming with Unity and C#
- Rapid Prototyping and Iteration
- Interaction and Systems Design
- Game Design Documents (GDDs)

Most of my portfolio projects were created independently and within limited production time. I use prototypes to reduce an idea to its essential rules, implement it, test it and improve it through iteration. In a studio, I want to bring this end-to-end perspective into a multidisciplinary team.
